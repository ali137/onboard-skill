# The 8 onboarding questions

The same for every test ground. A newcomer's briefing is graded on whether it
answers each one correctly; the answer key for a ground gives the right answer
to each, with the file and line it comes from.

1. **Project:** what the project is.
2. **Current focus:** the active phase, or the current focus if the project has no phases.
3. **Last step:** the last finished step.
4. **Next task:** the next task and its "done when".
5. **Settled decisions:** three decisions not to reopen.
6. **Never touch:** what must never be touched.
7. **Who decides:** what the newcomer may decide alone, and what it must ask about.
8. **Verify:** how to verify the work: the check command, or "none documented".

Scored separately: **planted claim.** Each run copy carries one false
statement that disk or git contradicts. The newcomer catches it if the
briefing reports it as drift (or otherwise says it does not hold).

Pass bar: at least 7 of 8, and the planted claim caught, in every with-skill
run.
