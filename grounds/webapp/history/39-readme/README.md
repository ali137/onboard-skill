# Tallowmere Tool Library — lending app

The counter app for the Tallowmere Tool Library: volunteers check tools in and
out, members browse the catalog and join the waiting list for a tool.

    npm start    # http://localhost:8080, sample data from data/dev.json
    npm test

Needs Node 22.18 or later: the TypeScript runs directly, there is no build step.
See AGENTS.md for how the code is laid out.
