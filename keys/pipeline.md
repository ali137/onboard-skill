## 1. Project
**Answer:** gaugemoor, the data pipeline of Brindlemoor Rivers Trust, a small charity that runs river-level gauges on the River Brindle and Kestle Brook for volunteers and the district council's flood team. It reads the files the gauge loggers deliver (one file per station per day, 96 readings at 15-minute slots; five stations), screens and stores them, and produces a daily bulletin of river levels, flood alerts written to an outbox that the Trust's SMS gateway (outside the repo) sends, a council export of levels and flows, and (in progress) a weekly summary. A Python package (3.12 or later, standard library only) with pytest tests, one module per step under `gaugemoor/`, plus a command line (`python3 -m gaugemoor batch | bulletin | replay | export`).
**Required for the point:** a river-gauge / river-level data pipeline for a rivers charity (or "logger files in, bulletin, flood alerts and council export out"), and that it is a Python package or library with tests.
**Accept also:** naming the modules or the outputs instead of the purpose; "the Brindlemoor Rivers Trust's gauge pipeline"; flood alerting named as its main job alongside the bulletin and export.
**Not accepted:** a web app or service with a database or API server; the SMS gateway itself, or logger firmware/hardware; a project for a different domain.
